# HR Quick Workshop

Amazon Quick HR 智能助手 Workshop 素材包，包含 Chat Agent 和 Flows 两个实践场景，以及配套的操作手册、演示视频和测试数据。

## Workshop 内容

### 1. HR 面试助手（Chat Agent）

使用 Amazon Quick Space 构建 HR 简历库，并通过 Chat Agent 完成：

- 候选人简历查询与条件搜索
- 候选人对比和岗位推荐
- 面试进展查询与统计
- 候选人综合能力画像分析
- 基于固定 HTML 模板生成能力画像面板

### 2. 岗位调研与面试题纲准备（Flows）

使用 Amazon Quick Flows 构建自动化工作流，依次完成：

- 岗位市场调研
- 公司 JD 检索
- 候选人筛选与匹配
- 一小时面试题纲生成

## 快速体验

1. 根据对应目录中的 Workshop 手册完成 Space、Chat Agent 或 Flow 配置。
2. 上传目录中提供的简历、JD、跟踪表和模板文件。
3. 参考演示视频运行场景并验证结果。

> 所有候选人、联系方式、公司经历和招聘数据均为 Workshop 模拟素材，仅用于功能演示。
