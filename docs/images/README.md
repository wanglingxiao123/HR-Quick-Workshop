# Workshop 截图提交说明

请将需要展示在项目主 README 中的截图直接放入当前文件夹：

```text
docs/images/
```

共需要提供 **5 张图片**。请严格使用下方指定的文件名，这样收到图片后即可直接插入 README，无需再次重命名。

## 截图清单

### 1. HR 候选人分析助手

**文件名**

```text
00-candidate-analysis.png
```

**建议截图内容**

- Chat Agent 的完整页面。
- 页面中能够看出用户提出了候选人分析、岗位匹配或人才画像相关问题。
- 优先展示已经生成的人才画像页面。
- 如果人才画像无法在一张图中完整展示，也可以截取包含候选人基本信息、能力分析和匹配建议的主要区域。

**希望用户一眼看到**

> 这个模块可以查询候选人资料，并基于简历生成人才画像或岗位匹配建议。

### 2. 岗位调研与面试题纲准备工作流

**文件名**

```text
01-interview-flow.png
```

**建议截图内容**

以下两种截图任选一种：

1. 完整的 Flow 编辑画布，能够看到市场调研、JD 检索、候选人匹配和面试题纲生成等主要步骤。
2. Run Mode 执行结果，能够看到输入岗位名称后生成的市场报告、候选人和面试题纲。

如果 Flow 画布过宽，请缩小浏览器比例，尽量让主要步骤同时出现在一张图中。

**希望用户一眼看到**

> 这个模块可以从一个岗位名称出发，自动完成岗位调研、候选人筛选和面试题纲生成。

## 图片要求

- 推荐格式：`PNG`
- 推荐宽度：`1600–2400 px`
- 推荐比例：横向截图，约 `16:9` 或 `16:10`
- 保持文字清晰，避免截图被过度压缩。
- 尽量使用相同的浏览器窗口宽度和页面缩放比例。
- 不要添加额外边框、水印、编号或大面积标注。
- 截图前关闭无关窗口、通知、个人头像菜单和浏览器下载栏。
- 如页面包含真实姓名、邮箱、手机号、账号、URL Token 或其他敏感信息，请先打码。
- Workshop 中的虚拟候选人姓名和模拟数据可以保留。
